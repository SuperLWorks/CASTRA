# Public-preview data and source boundary

CASTRA 0.1.0-preview.1 is an experimental browser-client demonstration, not a
production deployment kit. The public tree has no server-side command service,
operational database, provider credentials, agent launcher or private Git history.

## Historical source reference not published

The bundled demonstration contains historical CASTRA examples and synthetic
demonstration values. Stable record IDs, relationships and historical statuses
are retained so the example planning workflow remains reproducible. They are
not the Commander's current operational records, approvals or live provider
measurements. A historical passing check is not a passing check for this release.

Original private Notion page URLs and internal evidence links are withheld.
References to this section disclose that omission; they do not claim that the
underlying historical evidence is included or publicly verifiable. No record was
approved, reopened or closed by preparing this public package.

## Withheld internal reference

Internal operating instructions, historical evidence bodies, deployment runbooks,
agent profiles and launcher settings are not distributed. A reference to this
section is a limitation notice, not a replacement authority document or a file
that launches an agent. Configuration selections remain preferences for review,
not proof of an installed, connected or executing runtime.

The public-only Decision Inbox exclusion removes an unavailable internal route;
it does not remove a Public Demo capability. The demo's WebMCP registration,
input validation, proposal logic and protected human decisions remain intact.

The legacy migration validator's private parent-page binding is intentionally
unavailable here. This public copy cannot validate that private migration
package; its Public Demo does not use that path. The internal application is
unchanged, and this package is not a replacement for its operational validator.

## License inventory provenance

The preserved third-party inventory records the dependency review performed on
September 2, 2026. Its lockfile hash identifies that historical review input.
This preview changes only the application version fields to `0.1.0-preview.1`;
dependency package entries are unchanged. The new source manifest binds the
current lockfile bytes. The historical inventory is not relabelled as a fresh
dependency audit. Dependencies and artwork retain their original licenses.

## Evaluation boundary

Use Public Demo with non-sensitive data. Its edits stay in page memory. Hosted
operations, migration, provider setup, purchases, agent execution and publication
are outside this public edition. Unfinished controls and integrations remain
labelled, and the known agent-card layout limitation is retained for follow-up.
